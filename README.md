# 📈 Engagement Rate Calculator

A social media analytics tool designed to measure user engagement rates based on likes, comments, and total follower counts.

🚀 **Live Demo**: [https://sucii-hub.github.io/engagement-calculator/](https://sucii-hub.github.io/engagement-calculator/)

---

## ⚡ Key Features
- **Engagement Rate Metrics**: Calculates precise engagement ratios for digital campaigns and social profiles.
- **Performance Classification**: Categorizes engagement performance into benchmarks (Low, Average, High).
- **Minimalist Interface**: Focused, distraction-free workflow for digital marketers and creators.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
